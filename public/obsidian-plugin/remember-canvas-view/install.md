手動インストールできます。`npm run build` 後、以下の手順で配置してください。

1. Obsidian の保管庫（Vault）フォルダを開きます。
2. `<Vault>/.obsidian/plugins/remember-canvas-view/` を作成します。
3. `manifest.json`、`main.js`、`versions.json` を作成したフォルダへコピーします。
4. Obsidian を再起動するか、「Reload app without saving」を実行します。
5. 「設定 → Community plugins」で「Remember Canvas View」を ON にします。
